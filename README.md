# 🎮 Dashboard de Vendas do Xbox Game Pass — Excel

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte do desafio **Criando um Dashboard de Vendas do Xbox com Excel**, da plataforma [DIO](https://www.dio.me/).

O objetivo é organizar e analisar dados de assinaturas do Xbox Game Pass por meio de um dashboard no Microsoft Excel, transformando dados brutos em informações visuais que facilitam a compreensão dos resultados e apoiam a tomada de decisões.

## 🎯 Objetivo

Analisar o faturamento de assinaturas anuais e as vendas de serviços adicionais, utilizando indicadores e tabelas de apoio para responder a perguntas de negócio.

## 📊 Análises realizadas

O projeto contempla as seguintes perguntas de negócio:

1. **Faturamento total:** qual é o faturamento das assinaturas anuais, considerando os serviços agregados?
2. **Renovação automática:** qual é o faturamento das assinaturas anuais com e sem renovação automática?
3. **EA Play Season Pass:** qual é o total de vendas do serviço, considerando os diferentes planos de assinatura?
4. **Minecraft Season Pass:** qual é o total de vendas do serviço, considerando os diferentes planos de assinatura?

## 🗂️ Estrutura do arquivo

A pasta de trabalho está organizada em quatro abas:

- **Assets:** reúne a paleta de cores e as referências visuais utilizadas no projeto.
- **Bases:** contém os dados de assinaturas utilizados nas análises.
- **Cálculos:** apresenta as tabelas de apoio e os resultados das perguntas de negócio.
- **Dashboard:** reúne a apresentação visual do projeto.

## 🛠️ Ferramentas utilizadas

- **Microsoft Excel:** organização dos dados, cálculos, tabelas de apoio e construção do dashboard.
- **GitHub:** versionamento e compartilhamento do projeto.

## ▶️ Como reproduzir o projeto

1. Clone este repositório ou faça o download dos arquivos.
2. Abra o arquivo `.xlsx` no Microsoft Excel.
3. Consulte a aba **Bases** para conhecer os dados utilizados.
4. Acesse a aba **Cálculos** para entender as análises e os resultados.
5. Visualize a aba **Dashboard** para explorar a apresentação dos dados.
